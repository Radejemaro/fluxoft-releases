# Fluxoft - instaladores

Descarga la versión vigente en [Releases](https://github.com/Radejemaro/fluxoft-releases/releases/latest):

- FluxoftPOS-<versión>-setup.exe: punto de venta (caja).
- FluxoftBackoffice-<versión>-setup.exe: Backoffice.
- FluxoftNegocio-<versión>-setup.exe: Negocio.

Las actualizaciones de las aplicaciones instaladas llegan automáticamente desde Fluxoft Control.
